# 수치 차트

먼저 비교·추세·분포·관계·정확한 값 조회 중 어떤 과제인지 정한다. `visual-rules.md`의 기법 표와 `components.md`의 실제 지원 범위를 사용한다.

- 관측 데이터, 식으로 계산한 모델, 설명용 가상 데이터를 구별하고 출처·단위·가정을 밝힌다. 개념 관계를 위해 가짜 수치를 만들지 않는다.
- 정확한 수량 비교에는 공통 축의 위치·길이를 우선한다. 순서 없는 범주를 선으로 연결하거나, 상관을 인과로 표현하지 않는다.
- 독자가 위치·길이·색을 무엇으로 읽어야 하는지 확인한다. 필요한 이름·단위는 해당 표시 가까이에 둔다. 축이 있는 그림은 수량과 범주를 구별하되 모든 그림에 x·y 표기를 강제하지 않는다. "같은 축" 같은 제작 메모 대신 독자에게 필요한 뜻을 전달한다.
- 나란히 비교하는 차트는 단위·축 범위·구간·범주 순서를 맞춘다. 막대는 0을 포함한다. 선·산점도의 축은 과제에 맞춰 정하고 범위를 명시한다.
- 정렬·집계·분모·결측·오차 구간의 의미를 확인한다. 신뢰 구간·표준편차·최솟값/최댓값을 혼동하지 않는다.
- 기본은 회색과 강조색 하나다. 이름·직접 라벨·선 모양으로도 구별한다. 여러 집단을 색으로 구별해야 하면 의미 있는 팔레트를 사용하고 대비를 검사한다.
- 표나 가까운 라벨로 원래 값을 확인할 수 있게 한다. 툴팁만으로 핵심 정보를 전달하지 않는다.
- 데이터가 많아지면 집계·부분 그림·표를 고려한다. 현재 MVP는 대규모 데이터 렌더러나 통계 분석 도구가 아니다.

설계 참고: [Cleveland & McGill, 1984](https://doi.org/10.1080/01621459.1984.10478080), [Heer & Bostock, 2010](https://idl.uw.edu/papers/crowdsourcing-graphical-perception), [Saket 등, 과제별 차트 비교](https://cagataydemiralp.io/projects/peng/peng-tvcg.pdf). 선택 규칙은 로컬에 있으므로 제작 때 이 링크를 다시 읽을 필요는 없다.
