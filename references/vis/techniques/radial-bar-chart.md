# 방사형 막대 차트 (`radial-bar-chart`)

차트 · 과제: 비교, 순위 · 데이터: 범주형, 수치형 · 형태: 호와 방사형

막대가 중심점에서 바깥으로 방사하는 원형 레이아웃의 막대 차트로, 정밀도보다 시각적 임팩트와 간결함을 추구.

출처: https://vis.hwpark.net/catalog/radial-bar-chart/

## 언제 사용하나

- 원형이 데이터의 성질을 강화하는 주기적 데이터(12개월, 24시간, 7일) 표시
- 제한된 공간에서 시각적으로 매력적인 대시보드나 인포그래픽 디스플레이 제작
- 범주 수가 적당하고(6-24개) 원 둘레에 잘 들어맞을 때
- 정확한 비교보다 대략적인 비교로 충분한 순위나 비교 표시
- 원형 형태가 주제적으로 적합할 때(시계 모양, 나침반 모양, 계절성)

## 이럴 땐 피하세요

- 막대 길이의 정밀한 비교가 필수적일 때는 표준 막대 차트가 더 정확합니다
- 범주 간 주기적이거나 원형적인 관계가 없어서 레이아웃이 의미를 더하지 못할 때
- 범주가 너무 적어(4개 미만) 원이 성겨 보이거나, 너무 많아(30개 초과) 쐐기가 지나치게 얇아질 때
- 추세나 시간에 따른 변화를 보여줄 때는 선 그래프가 시간적 연속성을 더 잘 보존합니다
- 낯선 레이아웃 때문에 청중이 혼란스러워할 수 있을 때

**대안:** `bar-chart`, `line-graph`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `sort`, `tooltip`

**관련 기법:** `bar-chart`, `pie-chart`, `radar-chart`
