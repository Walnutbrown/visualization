# 전체 + 세부 뷰 (`overview-and-detail`)

인터랙션 · 과제: 탐색 지원, 세부 정보 제공, 필터와 초점 · 데이터: 시간, 수치형, 지리, 네트워크 · 형태: -

동일 데이터를 서로 다른 스케일로 보여주는 두 개의 동기화된 뷰(전체 범위 개요와 확대된 세부 뷰)를 표시하는 인터랙션.

출처: https://vis.hwpark.net/catalog/overview-and-detail/

## 언제 사용하나

- 데이터가 넓은 범위(긴 시계열, 넓은 지리적 영역, 큰 네트워크)에 걸쳐 있어 전체 해상도로 표시하면 가독성이 떨어질 때.
- 사용자가 전역적 맥락을 유지하면서 동시에 국소적 세부를 살펴봐야 할 때.
- 줌-앤-팬만으로 탐색하면 사용자가 데이터 공간 안에서 위치를 잃게 되는 경우.
- 사용자가 시간 구간을 선택해야 하는 시계열 데이터 대시보드에서.
- 개요 자체가 (예: 전체 추세를 보여주는) 별도의 분석적 가치를 지닐 때, 세부 뷰와는 별개로.

## 이럴 땐 피하세요

- 화면 공간이 제한적일 때(모바일, 작은 임베디드 위젯)이라서 두 뷰가 공존할 수 없는 경우.
- 데이터가 단일 스케일에 편안하게 들어맞는다면 개요를 추가하는 것은 공간 낭비입니다.
- 초점+맥락 접근(피시아이, 왜곡)이 사용자가 기대하는 단일 뷰 경험을 더 잘 보존하는 경우.
- 개요가 너무 작아 쓸모가 없어질 경우(10,000개 노드 네트워크를 100x50 픽셀 미니맵에 표시하려는 시도).

**함께 쓰면 좋은 기법:** `area-graph`, `bar-chart`, `choropleth`, `heatmap`, `line-graph`, `network-diagram`, `scatterplot`

**관련 기법:** `brush-and-link`, `focus-and-context`, `hover-highlight`, `tooltip`, `zoom-and-pan`
