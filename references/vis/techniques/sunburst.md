# 선버스트 다이어그램 (`sunburst`)

차트 · 과제: 위계 구조, 구성 비율, 탐색 지원 · 데이터: 계층형, 범주형, 수치형 · 형태: 호와 방사형

각 링이 계층의 한 수준을 나타내고 호의 길이가 값을 인코딩하는 방사형 공간 채움 계층 시각화.

출처: https://vis.hwpark.net/catalog/sunburst/

## 언제 사용하나

- 부분-전체 관계를 가진 계층 데이터를 표시할 때(예: 파일 시스템 사용량, 조직 예산, 분류 체계 분석)
- 다단계 범주 구성을 인터랙티브하게 탐색할 때(클릭하여 하위 범주로 드릴다운)
- 2~4단계에 걸쳐 하위 범주가 부모 범주 안에 어떻게 중첩되는지 보여줄 때
- 프레젠테이션을 위해 시각적으로 매력적인 트리 구조 표현을 만들 때

## 이럴 땐 피하세요

- 호 사이의 정확한 크기 비교가 필요할 때는 호의 길이와 면적은 정확하게 비교하기 어려우므로, 대신 트리맵이나 막대 차트를 사용하세요
- 계층이 매우 깊을 때(5단계 초과)는 바깥 링이 읽을 수 없을 정도로 얇아지므로 트리 다이어그램이나 들여쓰기 목록을 사용하세요
- 의미 있는 계층이 없을 때는 평평한 데이터를 억지로 링에 넣지 말고 파이 차트나 막대 차트를 사용하세요
- 구조보다 정확한 값이 더 중요할 때는 표나 누적 막대 차트를 사용하세요
- 계층이 매우 넓을 때(노드당 형제가 많음)는 좁은 호가 구별되지 않으므로 넓은 계층을 더 잘 처리하는 트리맵을 사용하세요

**대안:** `treemap`, `bar-chart`, 트리 다이어그램, 들여쓰기 목록, `pie-chart`, 표, `stacked-bar-chart`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `drill-down`, `hover-highlight`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `donut-chart`, `treemap`
