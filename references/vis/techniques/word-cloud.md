# 워드 클라우드 (`word-cloud`)

차트 · 과제: 텍스트 분석, 순위, 비교 · 데이터: 텍스트, 수치형, 범주형 · 형태: 포함 관계

단어의 크기가 빈도나 중요도에 비례하도록 배치하여 텍스트 데이터의 요약을 한눈에 보여주는 시각화.

출처: https://vis.hwpark.net/catalog/word-cloud/

## 언제 사용하나

- 텍스트 코퍼스에서 가장 흔한 용어들의 빠르고 시각적으로 흥미로운 개요를 제공할 때
- 개방형 설문 응답이나 소셜 미디어 논의를 대략적인 수준에서 요약할 때
- 사용자가 단어를 클릭해 관련 콘텐츠로 드릴다운할 수 있는 탐색 진입점을 만들 때
- 목표가 정밀함이 아니라 주제적 인상을 주는 것일 때 프레젠테이션에 시각적 다양성을 더할 때

## 이럴 땐 피하세요

- 정확한 빈도 비교가 필요할 때는 값순으로 정렬된 막대 차트를 사용하세요
- 단어의 맥락이나 동시 출현이 중요할 때, 워드 클라우드는 단어를 맥락에서 떼어내므로, 대신 동시 출현 용어의 네트워크 다이어그램을 사용하세요
- 텍스트 데이터가 전처리되지 않았을 때는 불용어 제거, 어간 추출, 정규화가 필수적이며, 가공되지 않은 워드 클라우드는 오해를 불러일으킵니다
- 청중이 정량적 결론을 내려야 할 때는 크기-값 매핑이 분석 작업에 너무 부정확합니다
- 고유한 용어가 몇 개뿐일 때(10개 미만)는 막대 차트나 단순한 순위 목록이 더 명확하고 정보가 풍부합니다

**대안:** `bar-chart`, `network-diagram`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `dynamic-query`, `hover-highlight`, `tooltip`

**관련 기법:** `bar-chart`, `histogram`, `treemap`
