# 박스 플롯 (`box-plot`)

차트 · 과제: 분포, 비교, 편차 · 데이터: 수치형, 범주형 · 형태: 막대

데이터의 분포를 사분위수와 이상값으로 요약하는 차트.

출처: https://vis.hwpark.net/catalog/box-plot/

## 언제 사용하나

- 여러 범주에 걸친 연속형 변수의 분포 비교
- 데이터셋에서 이상값을 빠르게 식별
- 개별 포인트를 표시하면 시각적으로 복잡해지는 대규모 데이터셋 요약
- 분포의 대칭성과 왜도 평가
- 좁은 공간에서 퍼짐과 중심 경향 표시

## 이럴 땐 피하세요

- 대상 독자가 통계적 사분위수에 익숙하지 않을 때는 주석을 곁들인 히스토그램 또는 바이올린 플롯을 고려하세요
- 분포의 형태(이봉형, 다봉형)가 중요할 때는 대신 바이올린 플롯이나 밀도 플롯을 사용하세요
- 데이터 포인트가 매우 적을 때(10개 미만)는 원자료 포인트를 스트립 플롯이나 점 도표로 직접 표시하세요
- 분포가 아니라 정확한 값을 비교할 때는 오차 막대가 있는 막대 차트를 사용하세요

**대안:** `histogram`, `violin-plot`, 밀도 플롯, 스트립 플롯, 점 도표, `bar-chart`

**함께 쓰면 좋은 기법:** `brush-and-link`, `hover-highlight`, `linked-views`, `sort`, `tooltip`

**관련 기법:** `bar-chart`, `histogram`, `scatterplot`, `violin-plot`
