# 트리맵 (`treemap`)

차트 · 과제: 위계 구조, 구성 비율 · 데이터: 계층형, 수치형, 범주형 · 형태: 포함 관계

계층적 데이터를 중첩된 사각형의 면적으로 표현하는 차트.

출처: https://vis.hwpark.net/catalog/treemap/

## 언제 사용하나

- 전체 수량이 계층 구조에 걸쳐 어떻게 분포되는지 표시(예산, 디스크 사용량, 시가총액)
- 트리 구조 내 여러 항목의 상대적 크기 비교
- 제한된 화면 공간에서 대규모 계층적 데이터셋의 개요 제공
- 공간 효율이 중요하고 트리 다이어그램이 영역을 지나치게 낭비할 때

## 이럴 땐 피하세요

- 계층 구조 자체(부모-자식 링크, 깊이)가 수량보다 더 중요할 때는 네트워크 다이어그램이나 노드-링크 트리를 사용하세요
- 사각형 간 정밀한 비교가 필요할 때, 면적 지각은 길이보다 정확도가 낮으므로 막대 차트를 사용하세요
- 계층 구조가 없는 데이터의 경우에는 막대 차트나 누적 막대 차트를 사용하세요
- 리프 노드가 매우 적을 때(10개 미만)는 중첩 레이아웃의 오버헤드가 이점 없이 복잡성만 더합니다

**대안:** `network-diagram`, `bar-chart`, `stacked-bar-chart`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `drill-down`, `focus-and-context`, `hover-highlight`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `stacked-bar-chart`, `sunburst`
