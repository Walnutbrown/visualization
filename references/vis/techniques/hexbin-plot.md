# 헥스빈 플롯 (`hexbin-plot`)

차트 · 과제: 분포, 관계, 밀도 · 데이터: 수치형 · 형태: 행렬과 격자

밀집된 점 군집을 육각형 빈으로 집계하고, 색이나 높이로 각 빈의 점 밀도를 인코딩하는 산점도 대안.

출처: https://vis.hwpark.net/catalog/hexbin-plot/

## 언제 사용하나

- 과다 표시로 개별 점이 보이지 않는 매우 큰 산점도(수천~수백만 개의 점)의 밀도를 시각화할 때
- 두 연속 변수의 결합 분포를 2차원 밀도 지도로 보여줄 때
- 이변량 데이터에서 군집, 능선, 공백 영역을 식별할 때
- 개별 점의 정체성보다 분포의 형태가 중요할 때 산점도를 대체할 때

## 이럴 땐 피하세요

- 개별 데이터 포인트가 반드시 보여야 하는 정체성이나 의미를 가질 때는 투명도나 지터를 적용한 산점도를 사용하세요
- 점이 약 200개 미만일 때는 산점도만으로도 이미 읽기 쉬우며, 헥스빈 처리는 과도한 집계가 됩니다
- 변수 간 관계가 밀도보다 중요할 때는 추세선을 곁들인 산점도를 사용하세요
- 하나 이상의 변수가 범주형일 때는 대신 히트맵이나 스트립 플롯을 사용하세요
- 정확한 x/y 값을 읽어야 할 때는 육각형 집계가 개별 위치를 가립니다

**대안:** `scatterplot`, `heatmap`, 스트립 플롯

**함께 쓰면 좋은 기법:** `brush-and-link`, `cross-filter`, `hover-highlight`, `linked-views`, `tooltip`, `zoom-and-pan`

**관련 기법:** `choropleth`, `heatmap`, `histogram`, `scatterplot`
