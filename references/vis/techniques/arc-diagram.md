# 아크 다이어그램 (`arc-diagram`)

차트 · 과제: 네트워크, 관계 · 데이터: 네트워크, 범주형, 수치형 · 형태: 노드와 링크

노드를 하나의 직선 위에 배치하고 호(arc)로 연결하여 군집과 연결 패턴을 드러내는 네트워크 시각화.

출처: https://vis.hwpark.net/catalog/arc-diagram/

## 언제 사용하나

- 노드가 자연스러운 선형 순서를 가지는 네트워크의 연결을 시각화할 때
- 순차적 데이터에서 군집과 장거리 연결 다리를 드러낼 때
- 서사 속 등장인물의 동시 출현이나 시간순으로 정렬된 논문 간 인용 관계를 보여줄 때
- 네트워크 규모에 비해 포스 디렉티드 레이아웃이 지나치게 겹치거나 혼잡해질 때

## 이럴 땐 피하세요

- 네트워크에 자연스럽거나 의미 있는 노드 순서가 없을 때는 포스 레이아웃을 사용하는 네트워크 다이어그램이 더 나을 수 있습니다
- 매우 밀도가 높은 네트워크(노드당 엣지가 많은 경우)에서는 호들이 읽을 수 없는 뒤엉킴이 됩니다
- 노드의 공간적 배치가 중요할 때(예: 지리적 네트워크)는 지도나 공간적 네트워크 다이어그램을 사용하세요
- 계층 구조에 초점을 둘 때는 트리, 선버스트, 또는 트리맵을 사용하세요

**대안:** `network-diagram`, 지도, 트리, 선버스트, `treemap`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `sort`, `tooltip`

**관련 기법:** `bar-chart`, `heatmap`, `network-diagram`
