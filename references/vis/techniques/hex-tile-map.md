# 헥스 타일 맵 (`hex-tile-map`)

차트 · 과제: 지리, 비교 · 데이터: 지리, 수치형, 범주형 · 형태: 지도

지리적 영역을 동일 크기의 육각형 타일로 표현하여 공간 관계를 근사하면서 각 영역에 동일한 시각적 비중을 부여하는 지도.

출처: https://vis.hwpark.net/catalog/hex-tile-map/

## 언제 사용하나

- 지리적 면적이 크게 차이 나는 지역 간 데이터를 비교할 때(예: 미국 주, 세계 국가)
- 물리적 크기와 상관없이 모든 지역이 동등한 시각적 대표성을 가져야 할 때
- 각 타일이 미니 차트를 담는 지리적 스몰 멀티플을 만들 때
- 근사적인 지리적 배치로 충분하고 왜곡이 허용될 때
- 선거 지도, 인구통계 비교, 또는 지역별 지표 전반

## 이럴 땐 피하세요

- 정확한 지리적 형태나 위치가 중요할 때는 코로플레스 맵이나 표준 지도를 사용하세요
- 독자가 지리적 윤곽으로 지역을 식별해야 할 때(헥스 타일은 그 정보를 제거합니다)
- 점 단위 데이터나 연속적인 공간 분포의 경우에는 점 지도나 보간된 표면을 사용하세요
- 청중에게 지리가 낯설고 해석에 공간 인식이 중요할 때

**대안:** `choropleth`, `dot-map`

**함께 쓰면 좋은 기법:** `click-to-select`, `cross-filter`, `hover-highlight`, `linked-views`, `tooltip`

**관련 기법:** `bar-chart`, `choropleth`, `heatmap`
