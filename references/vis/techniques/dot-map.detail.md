# 점 지도 상세 (`dot-map`)

## 설명

점 지도는 지리적 배경 지도 위에 개별 점을 찍어 개별 사건, 개체, 또는 수량의 위치를 나타냅니다. 가장 단순한 형태에서는 각 점이 하나의 관측치(범죄 한 건, 상점 하나, 사람 한 명)에 대응하며, 그 지리 좌표에 표시됩니다. 점 밀도 변형에서는 각 점이 고정된 수의 단위(예: 점 1개 = 인구 500명)를 나타내며, 점들은 기반 데이터의 공간 분포를 근사하도록 지리적 경계 내에 분산 배치됩니다.

점 지도는 코로플레스 맵이 가려버리는 공간 패턴을 드러내는 데 탁월합니다. 코로플레스 맵은 영역 전체를 균일하게 색칠하기 때문에 영역 내부의 변이를 숨기고, 영역 크기에 따라 왜곡됩니다. 반면 점 지도는 실제로(혹은 대략적으로) 사물이 어디에 있는지를 보여주어, 밀집 지역, 공백 지역, 회랑(corridor), 그라디언트를 즉시 눈에 띄게 만듭니다. 미국의 유명한 "인종별 점 지도(racial dot map)"(더스틴 케이블(Dustin Cable), 2013)는 인종별로 색을 입혀 1인당 점 1개를 배치함으로써, 어떤 코로플레스 맵에서도 보이지 않던 동네 수준의 인종 분리 패턴을 드러낼 수 있음을 보여주었습니다.

점 지도의 과제는 밀집된 지역에서는 점들이 겹쳐 시각적 포화 상태를 만들고, 희박한 지역은 텅 비어 보인다는 것입니다. 확대/축소와 이동 인터랙션, 동적 집계(낮은 확대 수준에서 점을 클러스터로 묶는 것), 불투명도 조절은 다양한 밀도를 다루는 데 필수적입니다. 점의 크기와 점 하나당 대응하는 단위 수(N) 비율의 선택 또한 지도의 가독성에 결정적인 영향을 미칩니다.


## 구조

- 배경 지도: 경계, 해안선, 지형을 보여주는 지리적 참조 레이어입니다.
- 점: 지리 좌표에 배치되거나, (점 밀도 변형의 경우) 영역 경계 내에 무작위로 배치되는 원형 마크입니다.
- 점-값 비율: 각 점이 나타내는 고정된 단위 수입니다(예: 점 1개 = 인구 100명).
- 색상 인코딩: 범주(인종, 유형, 정당)에 따라 점을 색칠하여 여러 분포를 동시에 보여줍니다.
- 투명도/불투명도: 점의 겹침을 처리하고 시각적 누적을 통해 밀도를 드러내기 위해 적용됩니다.
- 범례: 각 점이 무엇을 나타내는지, 색상이 무엇을 의미하는지 설명합니다.

## 변형

- 일대일 점 지도: 각 점이 정확한 위치에서의 단일 관측치를 나타냅니다(사건 매핑, 시설 위치).
- 점 밀도 지도: 점이 영역 경계 내에 무작위로 배치되며, 각 점은 N개의 단위를 나타냅니다. 코로플레스 맵보다 더 섬세한 공간 정보를 제공합니다.
- 다범주 점 지도: 색상이 다른 점들이 같은 지도 위에서 여러 그룹의 공간 분포를 보여줍니다.
- 단계별 점 지도: 점의 크기가 값에 따라 달라지며, 버블 맵으로 변화합니다.
- 클러스터형 점 지도: 낮은 확대 수준에서는 인접한 점들이 개수 레이블이 붙은 클러스터로 집계되며, 확대하면 펼쳐집니다.

## 코드 레퍼런스

```js
// Observable Plot - dot map with geographic coordinates
Plot.plot({
  projection: "albers-usa",
  marks: [
    Plot.geo(statesMesh, { stroke: "#ccc", strokeWidth: 0.5 }),
    Plot.dot(events, {
      x: "longitude",
      y: "latitude",
      r: 2,
      fill: "type",
      opacity: 0.5,
      tip: true
    })
  ],
  color: { legend: true, label: "Event type" }
})
```
