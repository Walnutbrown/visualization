# 간트 차트 상세 (`gantt-chart`)

## 설명

간트 차트는 작업, 이벤트, 또는 활동을 타임라인을 따라 가로 막대로 표시하며, 각 막대의 왼쪽 끝은 시작 시각을, 오른쪽 끝은 종료 시각을 나타내고, 막대의 길이는 기간을 나타냅니다. 작업은 보통 범주, 단계, 또는 자원별로 그룹화되어 세로로 쌓이며, 무엇이 언제 일어나는지, 얼마나 걸리는지, 활동이 어디서 겹치는지를 보여주는 시각적 일정표를 만들어냅니다.

이 차트는 헨리 간트(Henry Gantt)가 1910년경 산업 생산 일정을 관리하기 위해 개발했으며, 이후 프로젝트 관리를 위한 지배적인 시각화 도구가 되었습니다. 간트 차트의 강점은 시간적 관계를 즉시 눈에 보이게 만든다는 데 있습니다: 병렬 작업, 순차적 의존관계, 마일스톤, 병목 현상 모두 타임라인 위 막대의 공간적 배열에서 드러납니다. 가로 시간 축은 공통 척도를 제공하여 기간 비교를 직관적으로 만들고 작업 간 타이밍을 쉽게 읽을 수 있게 합니다.

현대의 간트 차트는 종종 의존성 화살표(다른 작업이 시작되기 전에 완료되어야 하는 작업을 표시), 진행률 표시기(작업이 얼마나 완료되었는지 표시), 마일스톤(주요 날짜를 나타내는 다이아몬드 마커), 자원 배분(할당된 사람이나 팀에 따라 막대를 색칠)을 포함합니다. 인터랙티브 버전은 드래그로 일정 재조정, 시간 척도 간 확대/축소, 접을 수 있는 작업 계층을 지원하여 강력한 계획 및 모니터링 도구가 됩니다.


## 구조

- 작업 막대: 작업이나 이벤트마다 하나씩, 시작 시각부터 종료 시각까지 뻗은 가로 막대. 너비가 기간을 인코딩합니다.
- 작업 레이블: 각 막대의 왼쪽(또는 내부)에 있는 이름이나 설명으로, 각 활동을 식별합니다.
- 시간 축: 날짜, 주, 월, 또는 기타 시간 단위를 보여주는 가로 축.
- 작업 그룹화: 단계, 범주, 또는 자원에 따라 세로로 정리된 작업으로, 그룹 헤더나 들여쓰기가 함께 쓰이는 경우가 많습니다.
- 의존성 화살표: 한 작업의 끝과 다른 작업의 시작을 잇는 선으로, 선행 관계를 보여줍니다.
- 마일스톤: 주요 날짜(마감일, 검토, 산출물)에 표시되는 다이아몬드나 특수 마커.
- 진행률 채우기: 완료 비율을 보여주기 위해 각 막대 안에 더 진하거나 다른 색으로 채운 부분.
- 오늘 선: 일정 추적을 위해 현재 날짜를 표시하는 세로선.

## 변형

- 단순 간트: 의존관계나 진행률 없이 단순 막대로 표시된 작업으로, 개요용으로 사용됩니다.
- 의존관계가 있는 간트: 화살표가 선행 작업과 후행 작업을 연결하여 임계 경로를 보여줍니다.
- 자원 간트: 행이 작업이 아니라 자원(사람, 기계)을 나타내고, 막대는 각 자원이 무엇을 하고 있는지 보여줍니다.
- 마일스톤 차트: 마일스톤만 표시되며(기간 막대 없음), 상위 수준의 일정 커뮤니케이션에 유용합니다.
- 워터폴 일정: 작업이 엄격하게 순차적이어서 계단 형태를 만드는 간트 차트.
- 다단계 간트: 복잡한 프로젝트 관리를 위해 작업이 접을 수 있는 계층(프로젝트 > 단계 > 작업 > 하위 작업)으로 정리됩니다.

## 코드 레퍼런스

```js
// Observable Plot - Gantt-style timeline
Plot.plot({
  marks: [
    Plot.barX(tasks, {
      x1: "start",
      x2: "end",
      y: "task",
      fill: "phase",
      tip: true,
      rx: 4
    }),
    Plot.ruleX([new Date("2025-01-01")], {
      stroke: "red",
      strokeDasharray: "4,4"
    })
  ],
  x: { type: "time", label: "Date" },
  y: { label: null },
  color: { legend: true, label: "Phase" },
  marginLeft: 150
})
```
