# 파이 차트 (`pie-chart`)

차트 · 과제: 구성 비율 · 데이터: 범주형, 수치형 · 형태: 호와 방사형

전체에서 각 부분이 차지하는 비율을 부채꼴로 표현하는 차트.

출처: https://vis.hwpark.net/catalog/pie-chart/

## 언제 사용하나

- 카테고리가 2~5개일 때 부분이 전체를 어떻게 구성하는지 보여줄 때
- 한 카테고리가 우세하다는 점을 강조할 때(예: 시장 점유율 1위)
- 일반 청중에게 단순한 비율을 전달할 때
- "전체의 부분들"이라는 프레이밍이 핵심 메시지일 때

## 이럴 땐 피하세요

- 카테고리 간 정밀한 값을 비교할 때는 막대 차트를 사용하세요
- 카테고리가 6~7개를 넘을 때는 작은 조각을 읽을 수 없게 됩니다; 누적 막대 차트나 표를 사용하세요
- 데이터의 합이 의미 있는 전체가 되지 않을 때, 파이 차트는 100% 구성을 암시합니다
- 여러 그룹 간 비율을 비교할 때는 누적 막대 차트나 스몰 멀티플을 사용하세요
- 카테고리들의 값이 매우 비슷할 때는 각도 차이를 지각하기 어렵습니다

**대안:** `bar-chart`, `stacked-bar-chart`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `tooltip`

**관련 기법:** `bar-chart`, `donut-chart`, `stacked-bar-chart`
