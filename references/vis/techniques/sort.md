# 정렬 (`sort`)

인터랙션 · 과제: 순위, 탐색 지원, 비교 · 데이터: 범주형, 수치형, 시간 · 형태: -

선택한 데이터 속성에 따라 차트의 시각 요소를 재배열하여 순위 패턴을 드러내고 비교를 쉽게 하는 인터랙션.

출처: https://vis.hwpark.net/catalog/sort/

## 언제 사용하나

- 차트에 범주형 축(막대 차트, 점 도표)이 있고, 기본 순서(알파벳순, 입력 순서)가 순위 패턴을 드러내지 못할 때.
- 사용자가 어떤 열로든 정렬하고 싶어 할 수 있는 표와 표 형태의 시각화에서.
- 군집화나 유사도에 따라 행/열을 재배열하면 블록 구조가 드러나는 히트맵에서.
- 사용자의 과제가 명시적으로 순위에 관한 것일 때("어떤 항목이 가장 높은가?", "어떤 항목이 가장 낮은가?").
- 여러 정렬 기준(매출순 정렬 후 성장률순 정렬)을 비교하면 서로 다른 이야기가 드러날 때.

## 이럴 땐 피하세요

- 축에 보존해야 할 본질적으로 의미 있는 순서가 있을 때, 예를 들어 타임라인 상의 시간, 프로세스의 단계, "낮음/중간/높음" 같은 순서형 척도.
- 차트에 항목이 2~3개뿐일 때: 정렬은 무의미하며 인터랙션이 불필요한 복잡성만 더합니다.
- 두 축이 모두 연속형인 산점도에서: 한 축을 따라 정렬하면 2차원 공간 인코딩이 왜곡됩니다.
- 너무 많은 요소가 동시에 움직여(약 50개 이상) 애니메이션 재배열이 혼란스러울 때.

**함께 쓰면 좋은 기법:** `bar-chart`, `bubble-chart`, `heatmap`, `parallel-coordinates`, `scatterplot`, `stacked-bar-chart`

**관련 기법:** `animated-transition`, `click-to-select`, `dynamic-query`, `hover-highlight`, `tooltip`
