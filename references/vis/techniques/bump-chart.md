# 범프 차트 (`bump-chart`)

차트 · 과제: 시간에 따른 변화, 순위, 비교 · 데이터: 시간, 범주형, 수치형 · 형태: 선과 영역

Y축이 값이 아닌 순위를 나타내는 선 차트로, 시간이나 범주에 걸쳐 항목들의 상대적 순서 변화를 추적.

출처: https://vis.hwpark.net/catalog/bump-chart/

## 언제 사용하나

- 시간 구간에 걸쳐 순위가 어떻게 변하는지 추적할 때(예: 스포츠 리그 순위표, 시장 점유율 순위)
- 추월 사건이 핵심 이야기인 경쟁적 역학을 보여줄 때
- 절대값보다 상대적 위치가 더 중요할 때 서수적 위치를 비교할 때
- 정해진 기간 동안 순위의 안정성이나 변동성을 강조할 때

## 이럴 땐 피하세요

- 순위보다 절대값이 더 중요할 때는 선 그래프를 사용하세요
- 개체가 너무 많을 때(15개 초과)는 선이 뒤엉키므로 상위 N개로 필터링하거나 스몰 멀티플을 사용하세요
- 시간 구간이 단 두 개뿐일 때는 더 깔끔한 비교를 위해 기울기 차트를 사용하세요
- 순위가 거의 바뀌지 않을 때는 차트가 대부분 평평한 평행선만 보여주어 인사이트가 적으므로 표를 고려하세요
- 동점이 흔할 때는 범프 차트가 뚜렷한 순위를 필요로 하므로 동점 위치가 모호한 선 교차를 만듭니다

**대안:** `line-graph`, `small-multiples`, `slope-chart`, 표

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `linked-views`, `tooltip`

**관련 기법:** `bar-chart`, `line-graph`, `slope-chart`
