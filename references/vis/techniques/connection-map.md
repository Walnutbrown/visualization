# 연결 지도 (`connection-map`)

차트 · 과제: 네트워크, 지리, 관계 · 데이터: 지리, 네트워크, 범주형 · 형태: 지도

지리적 포인트 간의 연결을 선이나 호로 표시하여 공간에 걸친 관계의 네트워크 구조를 강조하는 지도.

출처: https://vis.hwpark.net/catalog/connection-map/

## 언제 사용하나

- 도시 간 항공 노선, 해상 항로, 통신 연결을 보여줄 때
- 네트워크의 지리적 구조(누가 누구와, 어디서 연결되어 있는지)를 시각화할 때
- 공간적 맥락에서 연결 허브와 주변부 노드를 강조할 때
- 지역 간 네트워크 커버리지(잘 연결된 지역과 고립된 지역)를 비교할 때
- 소셜 또는 비즈니스 네트워크에서 지리적 군집을 드러낼 때

## 이럴 땐 피하세요

- 연결의 존재 여부보다 흐름의 양이 더 중요할 때는 너비로 인코딩된 선을 사용하는 플로우 맵을 사용하세요
- 의미 있는 지리적 차원이 없을 때는 네트워크 다이어그램이나 인접 행렬을 사용하세요
- 연결 수가 매우 많고(1,000개 초과) 필터링 기능이 없을 때는 지도가 읽을 수 없는 망이 됩니다
- 정확한 경로가 중요할 때(예: 도로 내비게이션)는 추상적인 호가 아니라 경로 안내 지도를 사용하세요

**대안:** `flow-map`, `network-diagram`, `adjacency-matrix`

**함께 쓰면 좋은 기법:** `brush-and-link`, `click-to-select`, `hover-highlight`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `choropleth`, `network-diagram`
