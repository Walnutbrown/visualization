# 기울기 차트 (`slope-chart`)

차트 · 과제: 시간에 따른 변화, 비교, 순위 · 데이터: 수치형, 범주형, 시간 · 형태: 선과 영역

두 개의 수직 축을 선으로 연결하여 정확히 두 시점 또는 조건 간의 값이나 순위 변화를 보여주는 차트.

출처: https://vis.hwpark.net/catalog/slope-chart/

## 언제 사용하나

- 정확히 두 시점 사이의 값을 비교할 때(예: 개입 전 대 후)
- 어떤 개체가 개선되었는지, 악화되었는지, 안정적으로 유지되었는지 보여줄 때
- 두 시점 사이의 순위 역전을 강조할 때
- 그룹형 막대 차트를 대체하여 두 기간 비교를 더 간결하고 읽기 쉽게 만들 때

## 이럴 땐 피하세요

- 두 개보다 많은 시간 기간이 있을 때는 선 그래프나 범프 차트를 사용하세요
- 개체가 너무 많을 때(15개 초과)는 선이 과도하게 겹칩니다. 필터링하거나 스몰 멀티플을 사용하세요
- 절대값보다 비례적 변화가 덜 중요할 때는 퍼센트 레이블이 있는 덤벨 차트를 사용하세요
- 두 조건이 자연스러운 순서가 없을 때, 왼쪽에서 오른쪽으로의 흐름은 시간적 또는 논리적 순서를 암시합니다
- 개체를 범주별로 그룹화해야 할 때는 그룹형 막대 차트를 사용하세요

**대안:** `line-graph`, `bump-chart`, `small-multiples`, `dumbbell-chart`, 그룹형 막대 차트

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `tooltip`

**관련 기법:** `bar-chart`, `bump-chart`, `dumbbell-chart`, `line-graph`
