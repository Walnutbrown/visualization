# 원 패킹 (`circle-packing`)

차트 · 과제: 위계 구조, 구성 비율 · 데이터: 계층형, 수치형, 범주형 · 형태: 포함 관계

중첩된 원으로 계층적 데이터를 표현하며, 원의 면적이 정량적 값을, 중첩이 부모-자식 관계를 인코딩.

출처: https://vis.hwpark.net/catalog/circle-packing/

## 언제 사용하나

- 트리 구조와 리프 값이 모두 중요한 계층적 데이터 시각화
- 트리맵의 밀도보다 원의 유기적이고 친근한 미학을 선호할 때
- 다층 계층 구조 내 부분-전체 관계 표시
- 드릴다운을 활용한 인터랙티브 탐색: 부모를 클릭하면 자식으로 확대

## 이럴 땐 피하세요

- 공간 효율이 중요할 때, 트리맵은 공간의 100%를 채우지만, 원 패킹은 간격에서 약 9%를 낭비합니다
- 정확한 크기 비교가 중요할 때, 원은 정렬된 사각형보다 비교하기 어렵습니다
- 매우 깊은 계층 구조(4단계 초과)의 경우에는 중첩을 읽기 어려워집니다
- 평면적(비계층적) 데이터의 경우에는 대신 버블 차트를 사용하세요

**대안:** `treemap`, `bubble-chart`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `drill-down`, `hover-highlight`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `sunburst`, `treemap`
