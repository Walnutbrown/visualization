# 픽토그램 차트 (`pictogram`)

차트 · 과제: 비교, 구성 비율 · 데이터: 범주형, 수치형 · 형태: 행렬과 격자

반복되는 아이콘이나 기호로 데이터 값을 나타내며, 각 아이콘이 고정된 수량을 의미하는 차트.

출처: https://vis.hwpark.net/catalog/pictogram/

## 언제 사용하나

- 폭넓은 비전문가 청중에게 수량을 전달할 때
- 구체적인 아이콘을 통해 데이터를 감정적으로 몰입시키거나 기억에 남게 만들 때
- 소수의 카테고리(2~6개)에 걸쳐 단순한 비교를 보여줄 때
- 시각적 매력이 중요한 인포그래픽, 대시보드, 보고서에서

## 이럴 땐 피하세요

- 정확한 값 비교가 필수적일 때는 막대 차트를 사용하세요
- 카테고리가 많거나 값의 범위가 클 때는 아이콘 개수가 다루기 힘들어집니다
- 소수점 단위의 정밀도가 중요한 데이터일 때, 픽토그램은 값을 이산화합니다
- 시계열이나 추세 데이터의 경우에는 선 그래프를 사용하세요

**대안:** `bar-chart`, `line-graph`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `tooltip`

**관련 기법:** `bar-chart`, `donut-chart`, `pie-chart`
