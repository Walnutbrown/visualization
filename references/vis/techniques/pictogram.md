# 픽토그램 차트 (`pictogram`)

차트 · 과제: 비교, 구성 비율 · 데이터: 범주형, 수치형
이 스킬에서 그리는 방법: 직접 SVG

반복되는 아이콘이나 기호로 데이터 값을 나타내며, 각 아이콘이 고정된 수량을 의미하는 차트.

출처: https://vis.hwpark.net/catalog/pictogram/

## 설명

픽토그램 차트는 행이나 격자로 배열된 반복 아이콘이나 기호를 사용해 수량을 나타냅니다. 각 아이콘은 고정된 단위에 대응하며(예: 아이콘 하나가 10명을 의미), 아이콘의 총 개수가 각 카테고리의 값을 전달합니다. 이 기법은 1930년대 오토 노이라트(Otto Neurath)와 게르트 아른츠(Gerd Arntz)가 ISOTYPE(국제 타이포그래피 그림 교육 체계, International System of Typographic Picture Education) 아래 개척했으며, 지금도 일반 대중에게 가장 접근하기 쉬운 차트 형태 중 하나로 남아 있습니다.

픽토그램은 아이콘의 구체성을 활용하여 데이터를 즉각적으로 와닿게 만듭니다. 자동차 판매를 자동차 아이콘으로, 인구를 사람 아이콘으로 나타낸 차트는 데이터와 현실 세계의 대상 사이에 본능적인 연결감을 만들어냅니다. 이 때문에 픽토그램은 저널리즘, 공중보건 커뮤니케이션, 인포그래픽, 그리고 청중이 차트 해독에 익숙하지 않을 수 있는 교육 자료에서 특히 효과적입니다.

그 대가는 정밀도입니다: 값이 완전한 아이콘(또는 나머지를 위해 부분적으로 채워진 아이콘)으로 이산화되기 때문에, 막대 차트보다 정확한 값을 읽어내기가 어렵습니다. 픽토그램은 대략적인 비교로 충분하고 감정적 몰입이나 기억에 남는 것이 우선순위일 때 가장 효과적입니다.


## 언제 사용하나

- 폭넓은 비전문가 청중에게 수량을 전달할 때
- 구체적인 아이콘을 통해 데이터를 감정적으로 몰입시키거나 기억에 남게 만들 때
- 소수의 카테고리(2~6개)에 걸쳐 단순한 비교를 보여줄 때
- 시각적 매력이 중요한 인포그래픽, 대시보드, 보고서에서

## 이럴 땐 피하세요

- 정확한 값 비교가 필수적일 때는 막대 차트를 사용하세요
- 카테고리가 많거나 값의 범위가 클 때는 아이콘 개수가 다루기 힘들어집니다
- 소수점 단위의 정밀도가 중요한 데이터일 때, 픽토그램은 값을 이산화합니다
- 시계열이나 추세 데이터의 경우에는 선 그래프를 사용하세요

## 구조

- 아이콘(기호): 반복되는 그림 문자로, 각각 고정된 수량을 나타냅니다. 모든 아이콘은 크기가 같습니다.
- 행 또는 열: 카테고리별로 배열된 아이콘으로, 가로 방향이거나 격자 형태입니다.
- 범례 / 단위 레이블: 각 아이콘이 무엇을 나타내는지 설명하는 안내문입니다(예: "아이콘 1개 = 100명").
- 카테고리 레이블: 각 행이나 아이콘 그룹을 식별하는 텍스트입니다.
- 부분 아이콘: 나머지를 나타내기 위해 비례적으로 채워진 아이콘입니다(예: 반 단위는 반만 채움).

## 변형

- 격자 픽토그램: 아이콘이 고정된 격자(예: 10x10)로 배열되고 그중 일부가 강조되어 비율을 나타내며, 위험 커뮤니케이션에 흔히 사용됩니다.
- 누적 픽토그램: 각 행 안에 여러 아이콘 유형이나 색상을 사용해 구성을 보여줍니다.
- 와플 차트: 정사각형 격자를 색이 칠해진 셀로 채워 부분-전체 관계를 보여주는 가까운 친척 차트입니다.
- 비례 픽토그램: 개수 대신 아이콘 크기가 달라지지만, 이는 아이콘을 균일하게 유지한다는 ISOTYPE 원칙을 희생합니다.

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `tooltip`

**관련 기법:** `bar-chart`, `donut-chart`, `pie-chart`
