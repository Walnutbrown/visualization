# 코드 다이어그램 (`chord-diagram`)

차트 · 과제: 흐름, 관계, 비교 · 데이터: 네트워크, 범주형, 수치형 · 형태: 호와 방사형

노드를 원 둘레에 배치하고 가중 호로 연결하여 상호 연결 행렬의 흐름이나 관계의 크기를 보여주는 시각화.

출처: https://vis.hwpark.net/catalog/chord-diagram/

## 언제 사용하나

- 행렬 형태의 개체 간 흐름 시각화(무역, 이주, 통신, 의존성)
- 개체별 총 물량과 양자 관계 강도를 함께 보여주기
- 흐름 네트워크의 지배적 경로와 불균형 드러내기
- 데이터가 적당한 개체 수(5~15개)를 가진 정방 행렬(원천-목적지 표)일 때

## 이럴 땐 피하세요

- 개체가 많을 때(15개 초과)는 코드가 읽기 어려워집니다; 데이터를 집계하거나 히트맵을 사용하세요
- 흐름이 단방향이고 단계가 명확할 때는 대신 샌키 다이어그램을 사용하세요
- 공간적 배치가 중요할 때(지리 데이터)는 플로우 맵을 사용하세요
- 정확한 값이 중요할 때는 각도와 폭 비교는 부정확합니다; 표나 막대 차트를 사용하세요

**대안:** `heatmap`, `sankey-diagram`, `flow-map`, 표, `bar-chart`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `tooltip`

**관련 기법:** `heatmap`, `network-diagram`, `sankey-diagram`
