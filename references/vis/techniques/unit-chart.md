# 유닛 차트 (ISOTYPE) (`unit-chart`)

차트 · 과제: 비교, 구성 비율 · 데이터: 범주형, 수치형 · 형태: 행렬과 격자

각 아이콘이나 단위가 고정된 수량을 나타내며, 일대일 대응을 활용하여 수량과 비율을 직관적으로 보여주는 시각화.

출처: https://vis.hwpark.net/catalog/unit-chart/

## 언제 사용하나

- 폭넓고 비전문적인 청중에게 개수와 비율을 전달할 때
- 각 단위가 중요한 "Y 중 X" 관계를 보여줄 때(예: 위험 커뮤니케이션)
- 추상적인 통계를 구체적이고 사람 규모로 느껴지게 만들 때
- 전체가 작을 때(약 200 단위 미만)의 부분-전체 비교
- 인포그래픽과 편집형 데이터 시각화

## 이럴 땐 피하세요

- 전체 개수가 매우 클 때(수천, 수백만)는 아이콘을 셀 수 없게 되므로 막대 차트나 영역 그래프를 사용하세요
- 정확한 값 비교가 필요할 때는 막대 차트 같은 위치 기반 인코딩이 더 정확합니다
- 연속적인 데이터나 분포의 경우에는 히스토그램이나 바이올린 플롯을 사용하세요
- 청중이 분석적으로 정교하고 접근성보다 읽는 속도가 더 중요할 때

**대안:** `bar-chart`, `area-graph`, `histogram`, `violin-plot`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `tooltip`

**관련 기법:** `bar-chart`, `pie-chart`, `stacked-bar-chart`
