# 플로우 맵 (`flow-map`)

차트 · 과제: 흐름, 지리, 관계 · 데이터: 지리, 수치형, 범주형 · 형태: 지도

지리적 위치 간의 이동을 선이나 화살표로 나타내고, 선의 너비로 흐름의 크기를 인코딩하는 지도.

출처: https://vis.hwpark.net/catalog/flow-map/

## 언제 사용하나

- 지역, 도시, 국가 간의 이주 패턴을 보여줄 때
- 무역 흐름, 운송 항로, 공급망 이동을 시각화할 때
- 통근 패턴이나 교통량을 표시할 때
- 지리적 맥락과 이동 규모가 모두 중요할 때
- 출발지-도착지 데이터에서 주요 회랑과 뜻밖의 연결을 드러낼 때

## 이럴 땐 피하세요

- 지리적 맥락이 필요 없을 때, 추상적인 흐름에는 샌키 다이어그램이나 코드 다이어그램을 사용하세요
- 출발지-도착지 쌍이 너무 많을 때(100개 초과) 선이 읽을 수 없이 뒤엉킬 때는 먼저 필터링하거나 집계하세요
- 공간 패턴보다 정확한 흐름 값이 더 중요할 때는 막대 차트나 표를 사용하세요
- 흐름이 단일 지역 내에 있고 방향이 중요하지 않을 때는 인셋 막대 차트가 있는 코로플레스 맵을 사용하세요

**대안:** `sankey-diagram`, `chord-diagram`, `bar-chart`, `choropleth`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `choropleth`, `sankey-diagram`
