# 벤 다이어그램 상세 (`venn-diagram`)

## 설명

벤 다이어그램은 겹치는 닫힌 곡선(보통 원)을 사용해 집합을 나타내며, 곡선 사이의 공간적 겹침이 공통 소속을 나타냅니다. 다이어그램의 각 영역은 집합 소속의 고유한 조합에 대응합니다: A에만 속한 원소, B에만 속한 원소, A와 B 모두에 속한 원소, 또는 어디에도 속하지 않는 원소입니다. 영역의 면적이 그 안에 포함된 원소 수에 비례할 때, 이 다이어그램을 면적-비례 벤 다이어그램(또는 엄밀한 의미에서 오일러 다이어그램)이라고 부릅니다.

벤 다이어그램은 가장 보편적으로 인식되는 데이터 그래픽 중 하나입니다. 1880년 존 벤(John Venn)이 도입했고 레온하르트 오일러(Leonhard Euler)의 이전 연구를 바탕으로 하여, 논리학, 수학, 일상적 소통의 필수 요소가 되었습니다. 그 강점은 추상적인 집합 관계를 구체적이고 공간적으로 만드는 데 있습니다: "겹침"이 문자 그대로의 시각적 겹침이 되어, 차트 문해력이 없는 청중에게도 교집합이 즉각적으로 직관적으로 다가옵니다.

벤 다이어그램의 실용적 한계는 약 3~4개 집합입니다. 원이 두 개면 네 개의 영역이 생기고, 원이 세 개면 여덟 개의 영역이 생깁니다. 집합이 네 개가 되면 기하학이 복잡해지고(흔히 원 대신 타원이 필요), 다섯 개 이상이면 다이어그램은 거의 읽을 수 없게 됩니다. 더 많은 집합을 비교할 때는 UpSet 플롯이나 집합 행렬 다이어그램과 같은 대안적 표현이 선호됩니다.


## 구조

- 원(또는 타원): 각 집합을 나타내는 닫힌 곡선. 각 원에는 집합 이름이 레이블로 붙습니다.
- 겹침 영역: 두 개 이상의 원이 교차하는 영역으로, 여러 집합에 속하는 원소를 나타냅니다.
- 배타 영역: 다른 원과 겹치지 않는 각 원의 부분으로, 고유한 원소를 나타냅니다.
- 영역 레이블: 각 영역에 주석으로 붙는 개수나 백분율.
- 색상 인코딩: 각 집합에 서로 다른 반투명 색상이 지정됩니다. 겹침 영역은 혼합된 색상을 보여줍니다.
- 전체집합 경계: 모든 원소의 전체 범위를 나타내는 선택적 외곽 직사각형.

## 변형

- 면적-비례 벤(오일러 다이어그램): 원의 크기와 겹침 면적이 실제 개수에 비례하여, 더 정확한 표현을 제공합니다.
- 3집합 벤: 일곱 개의 고유 영역을 가진 세 개의 원으로, 가장 흔히 보이는 벤 변형입니다.
- UpSet 플롯: 많은 집합을 위한 행렬 기반 대안으로, 교집합 크기를 막대로, 집합 소속을 점 패턴으로 보여줍니다.
- 플라워 벤: 여러 집합(4~6개)을 위한 꽃잎 모양 영역이 방사형으로 배열됩니다.
- 인터랙티브 벤: 호버 시 영역이 하이라이트되고 상세 구성원 목록이나 개수가 표시됩니다.

## 코드 레퍼런스

```js
// D3 Venn Diagram using venn.js
import { VennDiagram } from "venn.js";
import * as d3 from "d3";

const sets = [
  { sets: ["A"], size: 68 },
  { sets: ["B"], size: 55 },
  { sets: ["A", "B"], size: 23 }
];

const chart = VennDiagram();
d3.select("#chart").datum(sets).call(chart);

d3.selectAll(".venn-circle path")
  .style("fill-opacity", 0.3)
  .style("stroke-width", 2);
```
