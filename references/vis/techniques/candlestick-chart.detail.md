# 캔들스틱 차트 상세 (`candlestick-chart`)

## 설명

캔들스틱 차트는 18세기 일본의 쌀 거래에서 유래했으며 오늘날 금융 시장에서 지배적인 차트 유형이 되었습니다. 각 캔들스틱은 하나의 시간 구간(일, 시간, 분)을 나타내며 시가, 종가, 최고가, 최저가 네 가지 값을 인코딩합니다. 캔들스틱의 두꺼운 "몸통"은 시가에서 종가까지를 나타내고, 가는 "꼬리"(또는 "그림자")는 고가와 저가까지 뻗어 있습니다.

색상은 방향을 인코딩합니다: 채워지거나 붉은 몸통은 종가가 시가보다 낮았음을(하락 구간), 비어있거나 초록 몸통은 종가가 더 높았음을(상승 구간) 나타냅니다. 이 색상 관례 덕분에 트레이더는 차트를 순식간에 훑어보며 강세나 약세 모멘텀을 파악할 수 있습니다. 연속된 캔들스틱의 패턴은 도지, 해머, 인걸핑 등 알아볼 수 있는 형태를 이루며, 기술적 분석가들은 이를 활용해 향후 가격 움직임을 예측합니다.

캔들스틱 차트는 정보 밀도가 높습니다(하나의 콤팩트한 마크에 시간 구간당 네 개의 값). 그러면서도 관례를 익히면 매우 읽기 쉽습니다. 종가만 연결한 선 차트로는 전달할 수 없는 구간 내 변동성(꼬리 길이), 방향성 움직임(몸통 색상), 시가-종가 관계(몸통 크기)를 모두 드러내기 때문에 금융 분석에서 단순한 선 차트를 능가합니다.


## 구조

- 몸통: 시가에서 종가까지 뻗은 두꺼운 직사각형 부분. 색상이 방향을 나타냅니다(초록/빈 몸통 = 상승, 빨강/채워진 몸통 = 하락).
- 위 꼬리(그림자): 몸통 위쪽에서 그 구간의 고가까지 뻗은 가는 선.
- 아래 꼬리(그림자): 몸통 아래쪽에서 그 구간의 저가까지 뻗은 가는 선.
- 시간 축: 시간 구간(일, 시간 등)을 나타내는 수평 축.
- 가격 축: 가격 값을 보여주는 수직 축.
- 거래량 막대: 캔들스틱 차트 아래의 보조 패널에 자주 표시되며, 막대 높이가 구간별 거래량을 인코딩합니다.

## 변형

- OHLC 바 차트: 채워진 몸통 대신 수직선의 왼쪽(시가)과 오른쪽(종가)에 수평 눈금을 두어 시각적 무게감을 줄입니다.
- 헤이킨아시: 평균화된 OHLC 값을 사용해 노이즈를 줄이고 추세를 더 잘 보이게 하는 평활화 변형.
- 빈 몸통 캔들스틱: 종가가 이전 종가보다 높으면 몸통이 비고, 낮으면 채워져 두 번째 비교 차원을 추가합니다.
- 렌코 차트: 시간을 무시하고 고정된 가격 증분 단위의 박스를 그려 노이즈를 걸러냅니다.
- 카기 차트: 가격이 임계값만큼 반전할 때만 방향을 바꾸는 수직선을 사용합니다.

## 코드 레퍼런스

```js
// Observable Plot - candlestick chart
Plot.plot({
  marks: [
    // Wicks (high-low)
    Plot.ruleX(data, {
      x: "date",
      y1: "low",
      y2: "high",
      stroke: "#888"
    }),
    // Bodies (open-close)
    Plot.barY(data, {
      x: "date",
      y1: "open",
      y2: "close",
      fill: d => d.close >= d.open ? "#22c55e" : "#ef4444",
      tip: true
    })
  ],
  x: { type: "band", label: "Date" },
  y: { label: "Price ($)" }
})
```
