# 코로플레스 맵 (`choropleth`)

차트 · 과제: 지리, 비교, 분포 · 데이터: 지리, 수치형, 범주형 · 형태: 지도

지리적 영역을 색상으로 구분하여 데이터 패턴을 표현하는 지도.

출처: https://vis.hwpark.net/catalog/choropleth/

## 언제 사용하나

- 지리적 영역에 걸쳐 변수(예: 소득, 선거 결과, 감염률)가 어떻게 달라지는지 보여줄 때
- 지역 간 비율이나 정규화된 값(1인당 수치, 백분율)을 비교할 때
- 데이터의 지역적 군집, 그라디언트, 공간적 자기상관을 드러낼 때
- 비공간적 차트에서는 사라질 지리적 맥락을 제공할 때

## 이럴 땐 피하세요

- 비율이 아닌 원자료 건수를 표시할 때는 면적이 큰 영역이 인위적으로 중요해 보이게 됩니다. 데이터를 먼저 정규화하거나 지도 위에 버블 차트를 사용하십시오
- 영역의 크기가 극단적으로 다를 때(예: 러시아 vs. 룩셈부르크)는 대신 카토그램이나 타일 그리드 맵을 고려하십시오
- 정확한 값 비교가 필요할 때는 색상 구분이 정밀하지 않으므로 막대 차트나 툴팁과 함께 사용하십시오
- 데이터에 의미 있는 지리적 차원이 없을 때는 히트맵이나 막대 차트가 더 명확합니다
- 영역 집계가 아닌 포인트 단위 데이터를 가지고 있을 때는 점 밀도 지도나 지도 위 산점도를 사용하십시오

**대안:** `bubble-chart`, `cartogram`, 타일 그리드 맵, `bar-chart`, `heatmap`, 점 밀도 지도, `scatterplot`

**함께 쓰면 좋은 기법:** `click-to-select`, `cross-filter`, `hover-highlight`, `linked-views`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `histogram`, `line-graph`, `scatterplot`
