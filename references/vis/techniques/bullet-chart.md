# 불릿 차트 (`bullet-chart`)

차트 · 과제: 비교, 편차 · 데이터: 범주형, 수치형
이 스킬에서 그리는 방법: 직접 SVG

스티븐 퓨가 대시보드 게이지를 대체하기 위해 설계한 간결한 막대 차트로, 주요 측정치를 목표 및 성과 구간과 함께 표시.

출처: https://vis.hwpark.net/catalog/bullet-chart/

## 설명

불릿 차트는 스티븐 퓨(Stephen Few)가 2006년에 비즈니스 대시보드를 어지럽히던 게이지와 미터를 대체할 공간 효율적인 방법으로 고안했습니다. 하나의 수평 막대 안에 세 겹의 정보를 담습니다: 배경의 정성적 구간(예: 미흡/양호/우수), 어두운 막대로 표시되는 주요 측정치, 그리고 세로선으로 표시되는 비교 마커(보통 목표치나 벤치마크)입니다.

이러한 레이어드 인코딩 덕분에 불릿 차트는 놀라울 만큼 정보 밀도가 높습니다. 한 번 보는 것만으로 현재 값뿐 아니라 목표치와 어떻게 비교되는지, 어떤 정성적 구간에 속하는지까지 드러납니다. 불릿 차트 열 개를 수직으로 쌓은 대시보드는 원형 게이지 두 개 정도의 공간만 차지하면서도 훨씬 더 많은 정보를 전달하고 지표 간 직접 비교를 가능하게 합니다.

불릿 차트의 효과는 공통 척도상의 위치를 사용한다는 데서 나옵니다. 이는 가장 정확하게 지각되는 시각적 채널입니다. 값을 각도로 인코딩하는(정밀도가 낮은 채널) 원형 게이지와 달리, 불릿 차트는 값을 수직으로 정렬하여 서로 다른 지표 간 비교를 가능하게 합니다. 정성적 구간은 독자가 임계값을 암기할 필요 없이 맥락을 제공합니다.


## 언제 사용하나

- 공간이 제한적이고 많은 지표를 비교해야 하는 KPI 대시보드
- 실제 성과를 목표치나 벤치마크와 비교하여 보여줄 때
- 원형 게이지나 온도계 차트를 더 정밀한 대안으로 대체할 때
- 불릿 차트를 수직으로 쌓아 서로 다른 척도의 여러 지표를 비교할 때

## 이럴 땐 피하세요

- 표시할 의미 있는 목표치나 정성적 구간이 없는 경우에는 단순한 막대 차트를 사용하세요
- 추세를 보여주는 시계열 데이터의 경우에는 참조선이 있는 선 그래프를 사용하세요
- 청중이 불릿 차트에 익숙하지 않고 설명할 여지가 없는 경우에는 이 차트가 약간의 학습 곡선을 필요로 합니다
- 범주당 분포나 여러 데이터 포인트를 보여줄 때는 박스 플롯을 사용하세요

## 구조

- 정량적 척도: 숫자 값을 가진 수평 축입니다.
- 정성적 구간: 밝기가 점점 밝아지는 두세 개의 배경 띠입니다(예: 어두움 = 미흡, 중간 = 양호, 밝음 = 우수).
- 주요 측정치(기본 막대): 실제 값을 보여주는 어둡고 얇은 막대입니다.
- 비교 마커: 목표치나 벤치마크를 나타내는 짧은 세로선 또는 눈금 표시입니다.
- 범주 레이블: 측정 중인 지표를 식별하는 왼쪽의 텍스트입니다.

## 변형

- 수직 불릿 차트: 90도 회전한 형태로, 가로 행으로 배열할 때 유용합니다.
- 누적 불릿 대시보드: 여러 불릿 차트를 수직으로 쌓아 지표 간 비교를 위한 형태입니다.
- 발산형 불릿 차트: 기본 막대가 중심점의 왼쪽 또는 오른쪽으로 뻗어 목표치로부터의 양/음의 편차를 보여줍니다.
- 색상 코딩 불릿: 기본 막대의 색이 속한 정성적 구간에 따라 바뀝니다(빨강, 노랑, 초록).
