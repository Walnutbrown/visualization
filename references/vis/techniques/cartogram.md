# 카토그램 (`cartogram`)

차트 · 과제: 분포, 비교, 지리적 패턴 · 데이터: 지리, 수치형 · 형태: 지도

지리적 영역의 면적을 실제 땅 넓이가 아닌 데이터 변수에 비례하도록 왜곡한 지도.

출처: https://vis.hwpark.net/catalog/cartogram/

## 언제 사용하나

- 넓지만 인구밀도가 낮은 지역이 지배적으로 보이는 코로플레스 맵의 시각적 왜곡을 바로잡을 때
- 인구 가중 데이터(선거 결과, 인구당 질병 유병률)를 보여줄 때
- 측정 단위(사람, 달러, 표) 하나하나를 지도 위에 동등하게 보이게 할 때
- 언론 보도나 저널리즘 스토리텔링을 위해 기억에 남는 강렬한 시각화를 만들 때

## 이럴 땐 피하세요

- 지리적 형태와 위치가 정확하게 보존되어야 할 때는 코로플레스 맵이나 버블 맵을 사용하세요
- 청중이 해당 지리에 익숙하지 않을 때는 왜곡으로 인해 낯선 지역을 알아볼 수 없게 됩니다
- 정확한 공간 패턴(군집, 인접성)이 핵심일 때는 왜곡이 공간적 관계를 무너뜨립니다
- 데이터 변수가 물리적 면적과 강하게 상관관계를 가질 때는 카토그램이 일반 지도와 거의 동일하게 보이게 됩니다
- 매우 작은 지역이 아주 많을 때는 너무 작아져서 보거나 상호작용하기 어려워질 수 있습니다

**대안:** `choropleth`, `bubble-map`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `linked-views`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `bubble-chart`, `choropleth`
