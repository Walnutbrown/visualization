# 버블 맵 (`bubble-map`)

차트 · 과제: 지리, 비교, 분포 · 데이터: 지리, 수치형, 범주형 · 형태: 지도

지리적 위치에 원을 배치하고 원의 면적이 정량적 값에 비례하도록 하여 위치와 크기를 함께 보여주는 지도.

출처: https://vis.hwpark.net/catalog/bubble-map/

## 언제 사용하나

- 위치와 크기가 모두 중요한 지리적 위치에서 정량적 값을 보여줄 때
- 코로플레스 맵의 면적 왜곡 없이 도시, 시설, 지역 간 값을 비교할 때
- 지도 위에 이벤트 규모(지진, 발병, 사건)를 표시할 때
- 데이터가 영역 집계가 아니라 지점 위치를 나타낼 때
- 공간 분석을 위해 기준 지도 위에 정량적 차원을 오버레이할 때

## 이럴 땐 피하세요

- 데이터가 지역별 비율이나 밀도일 때는 코로플레스 맵을 사용하세요(비율을 버블로 표시하면 면적 기반 측정치를 왜곡하므로 부적절합니다)
- 버블이 심하게 겹쳐 개별 값을 읽을 수 없을 때는 먼저 집계하거나 필터링하세요
- 값의 정밀한 비교가 중요할 때는 면적 지각이 부정확합니다; 지도와 함께 막대 차트를 사용하세요
- 지리적 맥락이 중요하지 않을 때는 독립적인 버블 차트나 막대 차트를 사용하세요

**대안:** `choropleth`, `bar-chart`, `bubble-chart`

**함께 쓰면 좋은 기법:** `click-to-select`, `cross-filter`, `hover-highlight`, `linked-views`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `bubble-chart`, `choropleth`
