# 충적도 (`alluvial-diagram`)

차트 · 과제: 흐름, 시간에 따른 변화, 구성 비율 · 데이터: 범주형, 수치형 · 형태: 노드와 링크

여러 차원이나 시간 구간에 걸쳐 범주 소속이 어떻게 변하는지를 흐름 형태의 띠로 연결하여 보여주는 시각화.

출처: https://vis.hwpark.net/catalog/alluvial-diagram/

## 언제 사용하나

- 동일한 개체 집합이 시간이나 조건에 따라 범주적 그룹 간에 어떻게 재분포되는지 추적할 때
- 선거 간 정당 사이의 유권자 이동을 보여줄 때
- 전공, 학교, 졸업 결과 사이의 학생 흐름을 시각화할 때
- 설문 응답자가 여러 차수에 걸쳐 답변을 어떻게 바꾸는지 보여줄 때

## 이럴 땐 피하세요

- 서로 다른 단계의 노드가 근본적으로 다른 개체를 나타낼 때는 대신 샌키 다이어그램을 사용하세요
- 각 단계에 범주가 너무 많을 때(8개 초과)는 띠가 얇아지고 교차가 읽기 어려워집니다
- 시간 순서나 흐름의 방향이 의미가 없을 때는 다변량 탐색을 위해 평행 좌표 플롯을 사용하세요
- 정확한 정량 비교가 필요할 때는 곡선 띠가 정확한 크기 비교를 어렵게 만듭니다; 누적 막대 차트를 사용하세요
- 의미 있는 그룹화 차원이 없을 때는 총계를 보여주는 단순한 선 그래프로 충분할 수 있습니다

**대안:** `sankey-diagram`, `parallel-coordinates`, `stacked-bar-chart`, `line-graph`

**함께 쓰면 좋은 기법:** `animated-transition`, `brush-and-link`, `click-to-select`, `hover-highlight`, `tooltip`

**관련 기법:** `bar-chart`, `sankey-diagram`, `stacked-bar-chart`
