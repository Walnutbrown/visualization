# 클리블랜드 점 도표 (`cleveland-dot-plot`)

차트 · 과제: 비교, 순위 · 데이터: 범주형, 수치형 · 형태: 점

범주별 값을 정량 축 위의 점으로 비교하며, 면적이나 길이보다 위치를 강조하는 차트.

출처: https://vis.hwpark.net/catalog/cleveland-dot-plot/

## 언제 사용하나

- 많은 범주(10~50개 이상)에 걸쳐 값을 비교할 때, 막대 차트는 무겁게 느껴질 수 있습니다
- 크기나 면적보다 정확한 위치를 강조할 때
- 깔끔하고 미니멀한 레이아웃으로 순위를 보여줄 때
- 덤벨 변형으로 짝을 이룬 비교(전/후, 두 그룹)를 표시할 때
- 막대 차트보다 더 높은 데이터-잉크 비율을 원할 때

## 이럴 땐 피하세요

- 청중이 이 형식에 익숙하지 않고 막대 차트가 즉시 이해될 상황일 때
- 전체 중 부분을 보여줄 때는 누적 막대 차트나 파이 차트를 사용하세요
- 값들이 모두 매우 가까워 점의 위치가 겹칠 때는 지터링이나 다른 차트를 고려하세요
- 시계열 데이터의 경우에는 시간적 연속성을 보여주려면 선 그래프를 사용하세요

**대안:** `stacked-bar-chart`, `pie-chart`, `line-graph`

**함께 쓰면 좋은 기법:** `click-to-select`, `hover-highlight`, `sort`, `tooltip`

**관련 기법:** `bar-chart`, `line-graph`
