# 누적 막대 차트 (`stacked-bar-chart`)

차트 · 과제: 구성 비율, 비교 · 데이터: 범주형, 수치형 · 형태: 막대

각 막대를 하위 범주를 나타내는 구간으로 나누어 총합과 구성을 동시에 보여주는 막대 차트의 확장.

출처: https://vis.hwpark.net/catalog/stacked-bar-chart/

## 언제 사용하나

- 각 범주의 총합과 세부 구성을 동시에 보여줄 때
- 적당한 수의 범주(5~15개)에 걸쳐 구성을 비교할 때
- 구간을 명확히 볼 수 있을 만큼 충분히 큰 2~5개의 하위 범주가 있을 때
- 그룹 전반에서 부분이 전체에 기여하는 방식을 보여줄 때(설문 응답, 제품 라인별 매출)

## 이럴 땐 피하세요

- 그룹 간 개별 하위 범주의 정밀한 비교가 필수적일 때는 대신 모든 하위 범주를 공통 기준선에 정렬하는 그룹 막대 차트를 사용하세요
- 하위 범주가 많을 때(6개 초과)는 중간 구간이 가늘어져 읽기 어려운 조각이 됩니다
- 총합이 의미가 없거나 비교 불가능할 때, 누적은 가산적 구성을 전제로 합니다
- 범주가 독립적이어서 하위 그룹으로 분해되지 않을 때는 단순한 막대 차트를 사용하세요

**대안:** 그룹 막대 차트, `bar-chart`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `cross-filter`, `drill-down`, `hover-highlight`, `sort`, `tooltip`

**관련 기법:** `area-graph`, `bar-chart`, `donut-chart`, `pie-chart`
