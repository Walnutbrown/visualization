# 마리메코 차트 (`marimekko-chart`)

차트 · 과제: 구성 비율, 비교 · 데이터: 범주형, 수치형 · 형태: 막대

너비와 높이가 모두 변하는 2차원 누적 막대 차트로, 두 개의 정량적 차원을 동시에 인코딩.

출처: https://vis.hwpark.net/catalog/marimekko-chart/

## 언제 사용하나

- 세그먼트와 지역에 걸친 시장 점유율을 동시에 표시
- 범주의 크기와 내부 구성이 함께 어떻게 달라지는지 시각화
- 절대 크기와 상대적 구성이 모두 중요한 전략 분석
- 전체 규모가 다른 개체들의 포트폴리오 구성 비교

## 이럴 땐 피하세요

- 개별 세그먼트의 정밀한 비교가 필수적일 때는 가변 너비가 비교를 방해하므로 그룹 막대 차트를 사용하세요
- 어느 한 축에라도 범주가 많을 때(7개 초과)는 셀이 너무 작아져 읽기 어려워집니다
- 이 차트 유형에 익숙하지 않은 청중의 경우, 이중 인코딩은 설명이 필요합니다
- 구성만 중요할 때(범주의 상대적 크기는 중요하지 않을 때)는 균일한 너비의 누적 막대 차트를 사용하세요

**대안:** 그룹 막대 차트, `stacked-bar-chart`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `tooltip`

**관련 기법:** `bar-chart`, `stacked-bar-chart`, `treemap`
