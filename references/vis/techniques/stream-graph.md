# 스트림 그래프 (`stream-graph`)

차트 · 과제: 시간에 따른 변화, 구성 비율 · 데이터: 시간, 수치형, 범주형 · 형태: 선과 영역

유기적으로 흐르는 기준선을 가진 누적 영역 차트로, 여러 범주의 구성과 총합이 시간에 따라 어떻게 변하는지 보여줌.

출처: https://vis.hwpark.net/catalog/stream-graph/

## 언제 사용하나

- 전체 구성이 시간에 따라 어떻게 변하는지 보여줄 때(장르 인기도, 주제 트렌드, 종 풍부도)
- 시각적으로 매력적인 편집적, 내러티브적 시각화를 만들 때
- 정확한 값보다 변화의 전체적인 형태와 리듬이 더 중요한 경우
- 개별 추세와 총량을 모두 보여주고 싶은 5~20개 범주의 시간적 데이터를 표시할 때
- 표준 누적 영역 차트가 너무 딱딱해 보이고 청중이 미적 요소를 중시하는 경우

## 이럴 땐 피하세요

- 정확한 값 읽기가 필수적인 경우에는 떠 있는 기준선 때문에 개별 레이어 값을 읽기 어렵습니다; 누적 막대 차트나 선 그래프를 사용하세요
- 범주가 너무 많은 경우(20개 초과), 얇은 레이어는 읽기 어려워집니다
- 범주가 의미 있게 쌓이지 않는 경우(합산해도 의미 있는 총합이 되지 않음)에는 개별 선 그래프를 사용하세요
- 시간적이거나 순차적이지 않은 데이터의 경우, 흐르는 형태는 시간에 따른 연속성을 암시합니다
- 청중이 이 형식에 익숙하지 않아 형태를 잘못 해석할 수 있는 경우

**대안:** `stacked-bar-chart`, `line-graph`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `cross-filter`, `hover-highlight`, `tooltip`

**관련 기법:** `area-graph`, `line-graph`, `stacked-bar-chart`
