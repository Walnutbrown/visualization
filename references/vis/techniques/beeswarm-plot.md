# 비스웜 플롯 (`beeswarm-plot`)

차트 · 과제: 분포, 비교, 개별 값 · 데이터: 수치형, 범주형 · 형태: 점

점들을 겹치지 않게 옆으로 밀어 배치하여 개별 값을 모두 보여주면서 분포 형태를 드러내는 1차원 산점도.

출처: https://vis.hwpark.net/catalog/beeswarm-plot/

## 언제 사용하나

- 중소 규모 데이터셋(그룹당 20~500개 포인트)의 분포에서 모든 데이터 포인트 보여주기
- 개별 정체성을 유지하면서 범주 간 분포 비교하기
- 요약 통계로는 가려질 클러스터, 공백, 이상치 드러내기
- 표본 크기를 시각적으로 전달하기: 점의 개수가 곧 관측치의 개수

## 이럴 땐 피하세요

- 데이터셋이 매우 클 때(그룹당 500개 초과)는 스웜을 구분할 수 없게 됩니다; 바이올린 플롯이나 히스토그램을 사용하세요
- 개별 값보다 분포 형태가 더 중요할 때는 더 매끄러운 밀도 추정을 위해 바이올린 플롯을 사용하세요
- 두 축 모두에서 정밀한 위치 비교가 중요할 때는 옆으로의 변위가 임의적입니다; 두 축이 모두 실제 변수를 인코딩한다면 산점도를 사용하세요
- 요약 통계만 있고 원자료가 없을 때는 박스 플롯이나 오차 막대가 있는 막대 차트를 사용하세요

**대안:** `violin-plot`, `histogram`, `scatterplot`, `box-plot`, 오차 막대가 있는 막대 차트

**함께 쓰면 좋은 기법:** `brush-and-link`, `click-to-select`, `hover-highlight`, `sort`, `tooltip`

**관련 기법:** `bar-chart`, `box-plot`, `violin-plot`
