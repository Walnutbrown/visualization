# 재생 / 스크럽 (`playback-scrub`)

인터랙션 · 과제: 시간에 따른 변화, 탐색 지원, 서사 안내 · 데이터: 시간, 수치형 · 형태: -

재생, 일시 정지, 탐색 컨트롤로 시각화를 시간 또는 순서 차원에 따라 애니메이션하여 데이터의 변화를 관찰하는 인터랙션.

출처: https://vis.hwpark.net/catalog/playback-scrub/

## 언제 사용하나

- 데이터에 자연스러운 시간 차원(연, 월, 일)이 있고 분석 질문이 "시간에 따라 어떻게 변했는가?"일 때
- 개별 데이터 항목의 궤적이나 역동성이 최종 위치만큼이나 흥미로울 때
- 정적인 비교보다 애니메이션화된 변화가 더 몰입감 있는 발표와 스토리텔링에서
- 시간 단계가 너무 많아 스몰 멀티플로 표시하기 어렵지만 변화 과정 자체가 의미 있을 때
- 청중이 데이터가 "살아 움직이는" 모습을 보는 데서 이익을 얻을 때: 비전문가 시청자를 끌어들일 때

## 이럴 땐 피하세요

- 시간 지점이 2~3개뿐일 때는 단순한 전/후 비교나 스몰 멀티플이 더 명확하며 애니메이션이 필요 없습니다
- 예측 불가능한 방향으로 많은 항목이 동시에 움직일 때는 애니메이션이 혼란스럽고 읽기 어려워집니다
- 시간 지점 간 정확한 비교가 필요할 때는 정적인 나란히 배치한 뷰나 겹쳐 그린 궤적이 이전 애니메이션 프레임에 대한 기억보다 더 신뢰할 수 있습니다
- 시간적 패턴이 미묘하면 작은 변화는 애니메이션에서 지각하기 어렵습니다
- 청중이 보조 기술을 사용하면 스크린 리더는 애니메이션화된 공간적 변화를 전달할 수 없습니다

**함께 쓰면 좋은 기법:** `area-graph`, `bar-chart`, `bubble-chart`, `choropleth`, `heatmap`, `line-graph`, `network-diagram`, `scatterplot`

**관련 기법:** `animated-transition`, `focus-and-context`, `hover-highlight`, `parametric-manipulation`, `tooltip`
