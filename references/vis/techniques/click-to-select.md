# 클릭 선택 (`click-to-select`)

인터랙션 · 과제: 탐색 지원, 세부 정보 제공, 필터와 초점 · 데이터: 범주형, 수치형, 시간, 지리 · 형태: -

데이터 마크를 클릭하거나 탭하여 영구적으로 선택해 검토, 비교, 후속 작업에 활용할 수 있게 하는 인터랙션.

출처: https://vis.hwpark.net/catalog/click-to-select/

## 언제 사용하나

- 사용자가 비교나 자세한 검토를 위해 항목을 영속적으로 표시해야 할 때.
- 선택된 항목이 여러 연결 뷰 전반에 전파되어야 할 때.
- 선택 집합이 다른 작업(필터링, 내보내기, 주석)의 입력으로 사용될 때.
- 차트가 개별 마크를 안정적으로 클릭할 수 있을 만큼 성긴 경우.
- 호버 기반 인터랙션의 모바일/터치 대안으로서.

## 이럴 땐 피하세요

- 시청자가 값을 잠깐 훑어보기만 하면 될 때: 툴팁이 더 저비용입니다.
- 개별 마크를 클릭하는 것이 비현실적일 만큼 극도로 밀집된 플롯(수만 개의 겹치는 점)에서는: 대신 브러시 선택을 사용하세요.
- 선택된 항목에 대해 후속 작업이 전혀 없어 선택 상태가 시청자를 혼란스럽게 할 때.
- 시청자가 아닌 저자가 초점을 통제하는 가이드형/서사형 시각화에서.

**함께 쓰면 좋은 기법:** `bar-chart`, `bubble-chart`, `choropleth`, `heatmap`, `line-graph`, `network-diagram`, `parallel-coordinates`, `pie-chart`, `scatterplot`, `treemap`

**관련 기법:** `brush-and-link`, `cross-filter`, `hover-highlight`, `linked-views`, `tooltip`
