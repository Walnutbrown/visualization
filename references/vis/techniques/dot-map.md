# 점 지도 (`dot-map`)

차트 · 과제: 지리, 분포 · 데이터: 지리, 수치형, 범주형 · 형태: 지도

지리적 위치에 점을 찍어 현상의 공간 분포를 보여주며, 각 점이 하나 또는 일정 수의 발생을 나타내는 지도.

출처: https://vis.hwpark.net/catalog/dot-map/

## 언제 사용하나

- 포인트 사건(사건 발생, 관측, 시설)의 공간 분포를 보여줄 때
- 코로플레스 맵이 숨기는 영역 내부의 변이를 드러낼 때
- 세밀한 공간 해상도로 인구 또는 인구통계학적 분포를 표시할 때
- 데이터에 정확한 좌표가 있고 지리적 맥락이 중요할 때
- 색상으로 구분된 점을 이용해 둘 이상의 범주의 공간 분포를 비교할 때

## 이럴 땐 피하세요

- 포인트 위치 없이 영역 단위로 집계된 데이터를 가지고 있을 때는 대신 코로플레스 맵을 사용하십시오
- 점이 너무 밀집되어 지도 전체가 포화 상태가 될 때는 히트맵 오버레이나 육각형 비닝(hexbin)을 고려하십시오
- 지리적 차원이 중요하지 않을 때는 산점도나 히스토그램을 사용하십시오
- 지역별 정확한 개수가 중요할 때는 점이 세기 어려우므로 맥락 제공용 지도와 함께 막대 차트를 사용하십시오

**대안:** `choropleth`, `heatmap`, `scatterplot`, `histogram`, `bar-chart`

**함께 쓰면 좋은 기법:** `click-to-select`, `cross-filter`, `hover-highlight`, `linked-views`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `choropleth`, `histogram`
