# 레이더 차트 (`radar-chart`)

차트 · 과제: 비교, 편차, 분포 · 데이터: 수치형, 범주형 · 형태: 호와 방사형

중심에서 방사형으로 뻗는 축에 다변량 데이터를 표시하고 값을 연결하여 다각형을 형성하는 방사형 차트.

출처: https://vis.hwpark.net/catalog/radar-chart/

## 언제 사용하나

- 2~4개 개체의 다차원 프로필을 비교할 때(예: 제품 기능, 선수 스탯, 역량 평가)
- 개체가 여러 차원에서 균형 잡혀 있는지, 특정 속성으로 치우쳐 있는지 보여줄 때
- 전반적인 형태가 중요한 성과 스코어카드나 평가 요약을 표시할 때
- 청중이 이 형식에 익숙할 때 대시보드용 간결한 요약을 만들 때

## 이럴 땐 피하세요

- 개체 간 정확한 값 비교가 필요할 때는 대신 그룹형 막대 차트나 평행 좌표 플롯을 사용하십시오
- 겹치는 개체가 4~5개를 넘을 때는 차트를 읽을 수 없게 되므로, 평행 좌표 플롯이나 스몰 멀티플을 사용하십시오
- 축의 스케일이나 단위가 매우 다를 때는 먼저 정규화가 필요하며, 그렇게 해도 비교가 오해를 부를 수 있습니다
- 변수의 개수가 3개 미만일 때는 다각형이 퇴화하므로, 더 단순한 차트를 사용하십시오
- 축의 순서가 시각적 이야기에 큰 영향을 미칠 때는 순서가 더 명시적인 평행 좌표 플롯을 고려하십시오

**대안:** `bar-chart`, `parallel-coordinates`, `small-multiples`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `parametric-manipulation`, `tooltip`

**관련 기법:** `bar-chart`, `parallel-coordinates`, `scatterplot`
