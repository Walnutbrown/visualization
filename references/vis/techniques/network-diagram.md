# 네트워크 다이어그램 (`network-diagram`)

차트 · 과제: 네트워크, 관계, 탐색 지원 · 데이터: 네트워크, 범주형, 수치형 · 형태: 노드와 링크

개체를 점으로, 관계를 연결선으로 표현하며 물리 기반 포스 시뮬레이션으로 배치하는 노드-링크 시각화.

출처: https://vis.hwpark.net/catalog/network-diagram/

## 언제 사용하나

- 소셜 네트워크, 인용 네트워크, 조직적 관계의 구조를 보여줄 때
- 관계형 데이터에서 클러스터, 커뮤니티, 중심 노드를 식별할 때
- 개체들이 어떻게 연결되어 있고 어떤 연결이 가장 강한지 탐색할 때
- 의존성 그래프(소프트웨어 패키지, 공급망, 지식 그래프)를 시각화할 때
- 네트워크의 전체적인 위상 구조(허브-스포크, 스몰월드 등)를 전달할 때

## 이럴 땐 피하세요

- 네트워크가 매우 클 때(노드 5,000개 초과)는 헤어볼 문제로 포스 디렉티드 레이아웃을 읽을 수 없게 되므로, 인접 행렬이나 계층적 집계를 사용하세요
- 관계가 흐름으로 더 잘 표현될 때는 샌키 다이어그램이나 코드 다이어그램을 사용하세요
- 명확한 계층 구조가 있을 때는 트리 다이어그램이나 선버스트를 사용하세요
- 위상 구조보다 정확한 관계 값이 더 중요할 때는 히트맵이나 표를 사용하세요
- 데이터가 본질적으로 관계형이 아닐 때는 네트워크가 아닌 데이터를 억지로 그래프 레이아웃에 끼워 넣지 마세요

**대안:** `adjacency-matrix`, `sankey-diagram`, `chord-diagram`, 트리 다이어그램, 선버스트, `heatmap`, 표

**함께 쓰면 좋은 기법:** `brush-and-link`, `click-to-select`, `drill-down`, `hover-highlight`, `linked-views`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `heatmap`, `sankey-diagram`
