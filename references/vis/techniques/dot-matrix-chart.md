# 점 행렬 차트 (`dot-matrix-chart`)

차트 · 과제: 구성 비율, 비교 · 데이터: 범주형, 수치형 · 형태: 행렬과 격자

개별 점을 격자에 배열하여 수량이나 비율을 나타내고, 색으로 그룹 소속을 인코딩하는 차트.

출처: https://vis.hwpark.net/catalog/dot-matrix-chart/

## 언제 사용하나

- 전체 중 각 범주가 차지하는 비율 표시(예: 사용자 100명 중 42명)
- 위험이나 확률을 구체적이고 셀 수 있는 방식으로 전달
- 두 개 이상의 부분-전체 구성을 나란히 비교
- 일반 대중을 대상으로 한 인포그래픽과 발표

## 이럴 땐 피하세요

- 그룹이 많을 때(5개 초과)는 색상을 구별하기 어려워집니다
- 소수점까지 정확한 백분율이 필요할 때는 표나 주석이 달린 막대 차트를 사용하세요
- 시계열 데이터의 경우에는 선 그래프나 영역 그래프를 사용하세요
- 전체 개수가 매우 많을 때(점 500개 초과)는 점이 너무 작아져 구별할 수 없습니다

**대안:** `line-graph`, `area-graph`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `tooltip`

**관련 기법:** `bar-chart`, `pie-chart`, `stacked-bar-chart`
