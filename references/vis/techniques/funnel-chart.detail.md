# 퍼널 차트 상세 (`funnel-chart`)

## 설명

퍼널 차트는 큰 초기 수량에서 시작해 일련의 단계를 거치며 점점 좁아지는 프로세스를 시각화하며, 각 단계는 이전 단계 수치의 일부만을 유지합니다. 이 차트의 이름은 특징적인 형태에서 비롯됩니다: 위쪽은 넓고(모든 초기 진입을 나타냄) 아래쪽은 좁습니다(최종 전환이나 완료를 나타냄). 각 수평 밴드는 하나의 단계를 나타내며, 그 너비는 해당 단계의 수치에 비례합니다.

가장 흔한 활용 사례는 마케팅과 제품 설계에서의 전환 퍼널 분석입니다: 얼마나 많은 사용자가 인지에서 고려, 구매로 이어지는지 추적하는 것입니다. 하지만 이 패턴은 점진적으로 감소하는 모든 프로세스에 폭넓게 적용됩니다: 채용 파이프라인(지원자에서 채용까지), 의료(선별 검사에서 진단, 치료까지), 법적 절차(제소에서 재판, 판결까지), 또는 제조(원재료에서 완제품, 출하까지).

퍼널 차트는 단계에 자연스러운 순서가 있고, 주된 이야기가 단계 간 이탈률에 관한 것일 때 가장 효과적입니다. 시각적으로 좁아지는 형태는 이탈을 즉각적으로 전달하며, 인접한 밴드의 너비를 비교하면 어떤 전환에서 가장 많은 참여자를 잃는지 드러납니다. 백분율로 주석을 달면 이 차트는 병목 지점을 식별하는 강력한 진단 도구가 됩니다.


## 구조

- 단계 밴드: 단계마다 하나씩 있는 수평(또는 사다리꼴) 밴드로, 너비는 해당 단계의 수치에 비례합니다
- 단계 레이블: 각 프로세스 단계의 이름으로, 보통 밴드 왼쪽이나 내부에 표시됩니다
- 값 레이블: 각 밴드 위나 옆에 표시되는 건수 또는 백분율입니다
- 전환율 주석: 이전 단계에서 진행된 비율을 보여주는 선택적 레이블입니다
- 색상 그라디언트: 흔히 단일 색조에서 불투명도가 감소하거나, 위에서 아래로 순차적인 색상 스케일을 사용합니다
- 중앙 정렬: 대칭적인 퍼널 형태를 만들기 위해 밴드는 보통 수평으로 중앙 정렬됩니다

## 변형

- 비대칭 퍼널: 밴드가 중앙 정렬이 아니라 (막대 차트처럼) 왼쪽 정렬되어, 퍼널이라는 은유를 희생하는 대신 값 비교가 쉬워집니다
- 전환 레이블이 있는 퍼널: 각 단계 간 이탈률이 밴드 옆에 표시됩니다
- 누적 퍼널: 각 단계가 하위 범주(예: 트래픽 소스별)로 분해됩니다
- 역퍼널(피라미드): 위에서 아래로 갈수록 넓어지며, 단계를 거치며 값이 증가할 때(예: 도달 범위) 사용됩니다
- 수평 퍼널: 단계가 왼쪽에서 오른쪽으로 흐르며, 단계가 많을 때 유용합니다

## 코드 레퍼런스

```js
// Observable Plot - horizontal funnel as centered bar chart
Plot.plot({
  marks: [
    Plot.barX(stages, {
      y: "stage",
      x: "value",
      fill: "steelblue",
      fillOpacity: (d, i) => 1 - i * 0.15,
      tip: true
    }),
    Plot.text(stages, {
      y: "stage", x: "value",
      text: d => `${d.value} (${d.rate}%)`,
      dx: 5, textAnchor: "start"
    })
  ],
  y: {domain: stages.map(d => d.stage)}
})
```
