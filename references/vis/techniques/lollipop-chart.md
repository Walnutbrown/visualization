# 롤리팝 차트 (`lollipop-chart`)

차트 · 과제: 비교, 순위 · 데이터: 범주형, 수치형 · 형태: 점

막대 차트의 막대를 가는 선(줄기)과 점으로 대체하여 시각적 혼잡을 줄이면서 동일한 위치 인코딩을 유지하는 차트.

출처: https://vis.hwpark.net/catalog/lollipop-chart/

## 언제 사용하나

- 막대가 시각적으로 무겁게 느껴질 만큼 범주가 많을 때(10~50개 이상) 값을 비교할 때
- 대시보드와 보고서에서 막대 차트보다 더 깔끔하고 현대적인 대안을 만들 때
- 0 기준선이 의미 있는 참조값이고, 줄기를 통해 그 연결을 명시적으로 드러내고 싶을 때
- 채워진 면적의 크기보다 점의 위치가 더 중요한 순위를 보여줄 때
- 데이터 포인트가 많은 시각화에서 차트 정크를 줄이고 데이터-잉크 비율을 개선할 때

## 이럴 땐 피하세요

- 청중이 막대 차트를 강하게 기대하고 있어 롤리팝 형태가 혼란을 줄 수 있을 때
- 전체 중 부분이나 누적 구성을 보여줄 때는 누적 막대 차트를 사용하십시오
- 데이터 값이 매우 비슷해서 점들이 한데 뭉쳐 비교가 어려워질 때
- 막대가 유용한 2차 인코딩을 제공할 때(예: 각 막대 안에서 하위 범주를 보여주는 색상 채우기)

**대안:** `stacked-bar-chart`

**함께 쓰면 좋은 기법:** `animated-transition`, `click-to-select`, `hover-highlight`, `sort`, `tooltip`

**관련 기법:** `bar-chart`, `cleveland-dot-plot`, `line-graph`
