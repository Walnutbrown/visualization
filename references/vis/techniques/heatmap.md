# 히트맵 (`heatmap`)

차트 · 과제: 관계, 분포 · 데이터: 범주형, 수치형 · 형태: 행렬과 격자

행렬 형태의 셀에 색상 강도로 값의 크기를 표현하는 차트.

출처: https://vis.hwpark.net/catalog/heatmap/

## 언제 사용하나

- 값의 행렬을 시각화할 때(상관 행렬, 혼동 행렬, 설문 교차표)
- 시간적 패턴을 보여줄 때: 요일별-시간대별 활동, 여러 해에 걸친 월별 패턴
- 유전자 발현, 금융 수익률, 또는 정확한 값보다 패턴이 더 중요한 밀도 높은 표 형태 데이터를 표시할 때
- 많은 변수를 쌍으로 비교할 때(상관 히트맵)

## 이럴 땐 피하세요

- 정확한 값 비교가 필수적일 때는 막대 차트나 표를 사용하세요
- 데이터가 하나의 차원만 가질 때는 히스토그램이나 막대 차트를 사용하세요
- 연속적인 공간 데이터(지리적)의 경우에는 코로플레스 맵이나 보간된 표면을 사용하세요
- 셀이 매우 적을 때(예: 2x2 격자)는 색상 스케일을 쓰는 오버헤드가 정당화되지 않습니다

**대안:** `bar-chart`, `histogram`, `choropleth`

**함께 쓰면 좋은 기법:** `click-to-select`, `cross-filter`, `dynamic-query`, `hover-highlight`, `sort`, `tooltip`, `zoom-and-pan`

**관련 기법:** `bar-chart`, `histogram`, `line-graph`
